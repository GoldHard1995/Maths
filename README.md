# 有向數方塊世界

香港中一有向數課堂練習。四個獨立遊戲，自由選關，建議每次約十分鐘；拆括號與計算每局十二題，其餘每局十六題，不設倒數或限時扣分。

- 數線定位：−10 至 +10，完整刻度至部分標示。第一次答錯給方向提示；第二次起逐格示範，之後重試。
- 比較大小：−10 至 +10，包含負數及相等情況。答錯後才提供數線。
- 數線移動：依次選方向、步數及終點；涵蓋加／減正／負數。起點、終點和移動路徑均在 −10 至 +10。
- 拆括號與計算：由淺入深練習十二題完整加減算式：四題小數值正數起始的兩項計算、四題負數起始的兩項計算、四題三項計算；三項題會同時檢查兩個括號的符號；兩步分別判斷。題目及答案均在 −20 至 +20。

遊戲不設帳戶、不儲存或上傳學生答案。React 記憶體內的本局結果在返回選關或重新整理後清除。Sites 平台的網站存取設定與遊戲本身分開管理；目前先作私人試玩。

## 開發與檢查

- `npm run dev`：本機預覽。
- `npm run build`：正式版本。
- `npx tsc --noEmit`：型別檢查。
- `node --test tests/game.test.mjs`：數學、出題範圍及作答狀態測試，使用 Node 22.13 或更新版本。

已通過九組測試，包括大量生成題目範圍檢查和所有遊戲的完整流程。未進行瀏覽器點擊或實機平板測試。

有支援時，透過 WebMCP 註冊 `start_number_game`，沿用畫面相同的開始遊戲動作。一般瀏覽器不支援時直接略過；本次環境沒有可用的 WebMCP 驗證上下文，未驗證此介面。

背景為本專案生成的原創方塊景觀，不含 Minecraft 標誌或遊戲原有資產。

所有遊戲每局隨機抽題，同局無重複。除數線定位外，重玩避開上一局全部題目；定位範圍僅二十一個整數，因此保證同局不重複、零一定出現且同題號不沿用上一局目標。比較大小依非負數、跨零比較、負數比較遞進；拆括號每個難度內隨機排列四種符號組合。上一局題目只保留在本頁記憶體，重新整理即清除；不儲存學生答案。
