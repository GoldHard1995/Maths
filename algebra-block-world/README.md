# 代數方塊世界

香港中一代數練習網頁遊戲。UI 直接沿用「有向數方塊世界」，設有七個獨立關卡，每關十五題，依次為五題基礎、五題核心及五題綜合。

## 關卡

- 文字變代數
- 代數式加減
- 代數式乘法及除法
- 拆括號
- 含拆括號的四則化簡
- 公式代入
- 數列代入

代數式只使用 `x`、`y`、`a`、`b`，每題最多兩個字母，不產生字母乘積或指數。直接輸入題接受數學上等值的寫法。公式及數列的數值答案介乎 −50 至 100。

## 本機檢查

- `npm test`
- `npx tsc --noEmit`
- `npm run build`

排行榜 UI 已保留，但不設預設後端網址。未設定 `NEXT_PUBLIC_LEADERBOARD_URL` 時，學生可略過上傳並返回選關。本階段未包含 Google Apps Script 或部署設定。
