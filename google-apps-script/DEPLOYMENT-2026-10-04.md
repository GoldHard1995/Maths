# Apps Script 正式更新紀錄

日期：2026-10-04。依 Ken 的「更新到 script」指示，將原有正式部署由版本 13 更新至版本 15。沿用原有部署 ID、網址、匿名存取設定及執行身份。

- 來源：GitHub new-update `53aadad` 的 `google-apps-script/Code.gs`，已與版本 15 的 API 讀回內容逐字核對。原有 appsscript manifest 保留。
- 平台目錄：8 個世界、52 關及 75 枚襟章，包含坐標、百分法及恆等式。

## 更新前備份及測試

- 已建立原試算表的更新前備份及隔離測試副本；識別資料與詳細部署收據僅保存在本機，未納入 Git。
- 版本 14 僅作測試試算表的臨時部署，正式流量在測試期間維持版本 13。測試後已移除臨時部署及測試專用 Script Property，兩份試算表保留。
- 在隔離試算表初始化及遷移後，原有紀錄與襟章資料的雜湊、行數及 16 個成績欄位均維持不變。
- 六關恆等式上傳、每關 150 分個人最佳、900 分總榜及 8 枚新襟章通過。重複提交編號不新增紀錄；無效遊戲被拒絕。坐標、百分法成績及排行榜隔離通過。

## 正式驗證及資料保留

正式 Web App 及 Preview 的 `/api/platform` 均讀回 8 個世界、52 關及 75 枚襟章。恆等式六關與總榜、坐標及百分法總榜、學生資料及三個新世界的個人最佳讀取通過。

Chrome 在指定 Preview 驗證 Hub 載入 75 枚襟章，恆等式六張個人最佳卡載入成功，排行榜正常開啟。正式驗證封鎖成績 POST，未寫入測試成績。

正式試算表原有欄位、成績及已取得襟章保留；沒有執行正式資料遷移或清空。完美主義者的新取得門檻為 52 關，歷史取得日期仍有效。此更新只更新正式 Apps Script 後端，未合併 main 或部署靜態網站正式流量。

如需回復後端，可將同一部署的版本改回保留的版本 13；試算表更新前備份亦已保留。
