# 方程方塊世界

香港中一「一元一次方程」練習網頁遊戲。UI 直接沿用「代數方塊世界」，設六個獨立關卡；每關十五題，依次為五題基礎、五題核心及五題綜合。

## 關卡

- 簡易方程
- 含同類項的方程
- 含括號的方程
- 含分數的方程
- 建立方程
- 方程應用

解方程關卡接受整數或等值分數答案；建立方程會判定數學上等價的方程。應用題分為建立方程、求值及單位三步。

## 本機檢查

- `npm test`
- `npx tsc --noEmit`
- `npm run lint`
- `npm run build`
- `npm run build:github`

成績使用獨立的 `linear-equation` 世界識別，並接駁共用數學遊戲平台。
