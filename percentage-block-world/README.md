# 百分法方塊世界

香港中一「百分法（1）」練習。畫面以本機多項式方塊世界為範本，採用 Minecraft 方塊花海背景，保留原有面板、按鍵、字型、計分及流程。

## 關卡與作答

每關 15 題，固定 5 基礎、5 核心、5 綜合。百分數互化及百分數應用的前 10 題為選擇題，其餘四關的首 5 題為選擇題；其餘題目輸入最終答案。

1. 百分數互化：整數百分率 1%–300%，小數答案最多兩位。
2. 百分數應用：求百分率、部分、全部、餘下部分及兩層百分率；總數 20–1000。
3. 百分增加：單次增加、反求原值；整數增加率 1%–100%。
4. 百分減少：單次減少、反求原值；整數減少率 1%–99%。
5. 盈利與虧蝕：單件、整批及損壞貨品交易；盈利率至 100%，虧蝕率低於 100%。
6. 折扣：折數、售價、標價、多件商品及結合盈虧；折扣百分數為 5%–90%，以 5% 遞增。

生活題的基礎及核心均為正向計算：百分數應用求部分、百分率、餘下數量及餘下百分率；增加／減少由原值求變化量、新值或百分變化；盈虧由成本求售價、盈虧金額或盈虧率；折扣由標價求售價、節省金額或折扣百分數。反求原值、成本及標價只在綜合題出現。

生活應用選擇題的數量、金額及百分率選項均為正整數，取消 `0.48` 類的小數干擾選項。干擾答案按題目已知數值產生，例如部分與餘下混淆、加減方向錯誤、把百分數直接當金額，以及直式借位或個位計算錯誤；不足時補上相近的整數計算錯誤。折數仍以「八折」、「七五折」等中文表示，百分數互化則保留必需的小數與分數選項。

生活題使用日常情境。按物品限制合理價格，學校人數變化不超過 30%；運動隊學生不超過全校 40%，籃球隊為 5–60 人。人數、件數、價格、中間計算及答案均為整數，且不超過 1000。大幅減價及虧蝕交代為清貨；損壞貨品沒有回收收入，整批成本包括損壞商品。盈虧率以成本為基準，折扣百分數以標價為基準。

首次答對 10 分，重試答對 5 分，只有綜合題可放棄。正向計時達 1 小時結束，未完成局數不上傳。每局不重複，並按學生及關卡在同一瀏覽器分頁保存上一局識別，重新整理或返回 Hub 仍避題。

## 共用系統與路徑

- 子專案及成績使用獨立 `worldId = percentage`，六關總榜滿分 900 分。
- Cloudflare 路徑 `/percentage/`，由根目錄 `scripts/build-cloudflare.mjs` 組合。
- GitHub Pages 路徑 `/Maths/percentage/`，保留既有 Actions 發佈流程。
- 新增六枚關卡襟章、百分法大師、百分法完美大師；全平台完美主義者門檻為 46 關，既有授予紀錄保留。
- `google-apps-script/Code.gs` 必須在另獲部署授權後更新既有 Apps Script 版本；只更新前端無法在舊後端上傳百分法紀錄。

## 本機驗證

```sh
npm test
npm run lint
npx tsc --noEmit
npm run build:github
```

從根目錄執行 `npm run build:cloudflare` 驗證整站建置。瀏覽器測試使用本機靜態站及模擬平台回應，不向正式試算表寫入測試成績。

老師可參閱 [90 題核對樣本](docs/question-examples.md) 及 [驗證紀錄](docs/verification.md)。

背景及襟章使用內建 image_gen 產生，提示記錄見 [docs/asset-prompts.json](docs/asset-prompts.json)。素材位於 `public/world-flower-blocks.png` 及 `public/badges/`；Hub 副本位於 `maths-block-world-hub/public/badges/`。
