# 圖解法 × 判別式 Δ｜中四數學互動教室

專為香港中四數學課堂設計的互動教材，不需安裝、不需外部程式庫或登入。

## 四個教學環節

1. **觀察圖像**：比較 `y = x² − 4x + 3`、`+ 4`、`+ 5`，先提問，後展示交點。
2. **連繫 Δ**：逐例計算 `Δ = b² − 4ac`，對照兩個交點、一個交點、沒有交點。
3. **自由探索**：使用 `a`、`b`、`c` 滑桿，觀察開口方向、頂點及 Δ。`a` 不會等於 0。
4. **課堂挑戰**：共八題，即時顯示對錯、判別式計算及對應圖像。

## 使用方法

直接以瀏覽器開啟 `index.html`，或用靜態網站服務器託管整個資料夾。網頁無網絡依賴，能離線使用。

## 教學流程建議（40 分鐘）

- 0–10 分：觀察三條拋物線，先猜交點數，再揭示。
- 10–20 分：逐條計算 Δ，學生自行歸納 Δ 正、零、負與實根數目。
- 20–30 分：探索滑桿、特別討論 `a < 0` 與相切。
- 30–40 分：八題即時練習，最後用學生語句總結。

## 技術

HTML、CSS、JavaScript、SVG；純前端，無資料追蹤。程式處理不同實數解的數目（Δ = 0 為一個不同的實根／重根）。不涉及複數解教學。
